# Project 3 — UK Flight Punctuality & Airport Performance Intelligence

Official source: UK Civil Aviation Authority (CAA), 2025 Punctuality Statistics.

## Folder structure
- `data/raw/` — place the downloaded CAA annual Arrival/Departure CSV here
- `data/processed/` — cleaned datasets created later
- `python/` — Python/Jupyter work
- `sql/` — SQL analysis
- `powerbi/` — Power BI `.pbix` file later
- `screenshots/` — dashboard screenshots for GitHub

## Dataset to download
Download **2025 Annual Punctuality Statistics Full Analysis Arrival Departure (CSV)** from the official CAA 2025 punctuality page.

Rename it to:
`caa_2025_punctuality_arrival_departure.csv`

Then place it in:
`data/raw/`

Open `python/01_data_inspection.ipynb` in VS Code and complete the first five Python tasks yourself.
